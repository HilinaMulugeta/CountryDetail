# 🌍 Country Explorer

A simple web app that lets users search for a country and view real country information using a REST API.

This project is part of my Full Stack Software Development learning journey.

## ✨ Features

- Search for a country by name
- Display the country's flag
- Show capital, region, population, languages, currencies, and time zone
- Loading state while fetching data
- Error message for invalid country searches
- Default country displayed on page load

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- REST API
- `fetch()`
- Async/Await
- DOM Manipulation

## 📚 What I Practiced

- Fetching data from an API
- Working with JSON
- `async` / `await`
- Error handling
- Loading and success states
- DOM manipulation with `createElement()`
- Working with objects and arrays
- Optional chaining and nullish coalescing

## 🌐 API

Country data is provided by the University of Helsinki REST Countries API:

`https://studies.cs.helsinki.fi/restcountries/api/name/{name}`
